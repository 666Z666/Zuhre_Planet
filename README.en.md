# Zühre Planet — Project Guide

This repository is a development codebase for an adult-oriented listing/directory product. Production readiness, legal approval, a live domain, or user traffic have **not** been verified in this review.

The maintained architecture, current source map, security limits, and open gates are in [the Turkish project map](./docs/PROJE_HARITASI.md). Setup and commands are in [README.md](./README.md); prioritized work and acceptance criteria are in [docs/ROADMAP.md](./docs/ROADMAP.md). The project-local adult-marketplace safety workflow is at [`.agent/skills/adult-marketplace-safety-engineering/SKILL.md`](./.agent/skills/adult-marketplace-safety-engineering/SKILL.md).

The age gate is a self-attestation, not identity or age verification. Keep search indexing disabled until legal, age-assurance, consent/moderation, privacy, and operational release requirements are approved. Do not infer that a feature is production-ready just because its UI or dependency exists.
